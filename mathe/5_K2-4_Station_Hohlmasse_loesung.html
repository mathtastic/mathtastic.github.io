Lösung — Hohlmaße — ml, cl und l

Klasse 5 · Größen · K2-4
Aufgabe 1 — Was passt in welches Gefäß?
Frei. Anhaltspunkte: Trinkglas 200–250 ml · Tasse 150–200 ml · Wasserflasche 500 oder 1000 ml · Eimer 5–10 l.
c) Beispiel: Flasche 1000 ml, Glas 250 ml → 1000 : 250 = 4 mal.
Aufgabe 2 — Am Messbecher ablesen
Becher 1: kleiner Strich = 50 ml → 350 ml
Becher 2: kleiner Strich = 100 ml → 700 ml
Becher 3: kleiner Strich = 25 ml → 175 ml
Zuerst bestimmen, wie viel EIN kleiner Strich wert ist: Zwischen zwei beschrifteten Strichen liegt genau einer — er ist die Hälfte wert.
Aufgabe 3 — Hohlmaße umrechnen
3 l = 3000 ml · 5 l = 500 cl · 40 cl = 400 ml
2000 ml = 2 l · 600 cl = 6 l · 1 l 250 ml = 1250 ml
cl ist die Falle: von l zu cl ist die Umrechnungszahl 100, von cl zu ml nur 10.
Aufgabe 4 — Ordnen der Größe nach
1 l = 1000 ml · 330 ml · 25 cl = 250 ml · 1 l 50 ml = 1050 ml
Reihenfolge: 25 cl < 330 ml < 1 l < 1 l 50 ml
