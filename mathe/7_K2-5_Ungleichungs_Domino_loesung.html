Lösung — Ungleichungs-Domino

Terme und Gleichungen · Klasse 7 · Blatt 17
Aufgabe 1 — die elf Lösungsmengen
a) −3x − 4 < 5 → x > −3 b) 3x < 12 → x < 4 c) 6x > 12 → x > 2 d) 4x − 3 ≤ 17 → x ≤ 5 e) −x − 6 ≥ 4 → x ≤ −10 f) x + 5 ≥ 12 → x ≥ 7 g) 2x + 7 ≤ 19 → x ≤ 6 h) x − 6 > 2 → x > 8 i) x + 11 < 12 → x < 1 j) −2x + 3 > 11 → x < −4 k) 5x ≥ 45 → x ≥ 9
Bei drei Ungleichungen wird durch eine negative Zahl geteilt — nur dort kehrt sich das Zeichen um.
Aufgabe 2 — die Kette
F → J → D → H → K → A → G → I → C → E → [fehlt] → B
Hinter E passt kein gedruckter Stein mehr — dort gehört der zwölfte hin. Von B geht es zurück zum Start.
Aufgabe 3 — der fehlende Stein
links: x ≤ −10 rechts: z. B. 3x + 4 ≥ 0 (Lösung x ≥ 0)
Links ist die Antwort eindeutig, rechts gibt es unendlich viele richtige — jede Ungleichung mit der Lösungsmenge x ≥ 0 passt.
⚡ Für Schnelle: Baue zwei zusätzliche Steine, die sich in die Kette schieben lassen, ohne sie zu zerbrechen.Zwei Ungleichungen mit derselben Lösungsmenge sind austauschbar
