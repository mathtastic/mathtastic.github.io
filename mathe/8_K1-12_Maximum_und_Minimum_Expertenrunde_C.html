Merksatz
Ein Term der Form a · (x − m)² + n hat für a > 0 ein Minimum und für a < 0 ein Maximum. Der Extremwert ist n, die zugehörige Belegung ist x = m.

FÜR DIE LEHRKRAFT
Es gibt viele richtige Terme. Jedes a mit dem passenden Vorzeichen zählt: bei einem Minimum a > 0, bei einem Maximum a < 0.
Ein Term zum Extremwert
Zum Beispiel:
a)Tmin = 12 für x = 15  →  T(x) = 2 · (x − 15)2 + 12
b)Tmax = 1 für x = −15  →  T(x) = −(x + 15)2 + 1
c)Tmin = 1 für x = 0  →  T(x) = x2 + 1
d)Tmax = 0 für x = −12  →  T(x) = −3 · (x + 12)2
e)Tmin = −2 für x = 0,5  →  T(x) = (x − 0,5)2 − 2
f)Tmin = 3,5 für x = −0,7  →  T(x) = 4 · (x + 0,7)2 + 3,5
L
Für die Lehrkraft
Vier Fassungen, eine Seite 2. Die Fassungen A bis D unterscheiden sich nur in Aufgabe 1. Aus jeder Expertengruppe geht je ein Kind in eine Stammgruppe zu viert.
Zeit: etwa 15 Minuten Expertengruppe, 15 Minuten Stammgruppe, danach Merksatz und Aufgabe 3 und 4.
Warum gilt die Regel? (x − m)² ist nie negativ und nur für x = m gleich 0. Mit a > 0 kommt zu n nie etwas Negatives dazu, n ist der kleinste Wert. Mit a < 0 umgekehrt.
Bei Aufgabe 3 und 4 gehören Extremwert und Belegung immer zusammen.
