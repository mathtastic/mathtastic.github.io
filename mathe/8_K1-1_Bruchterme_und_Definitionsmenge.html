Merke — Bruchterm und Definitionsmenge
Ein Term mit der Variablen im heißt . Die Zahlen der  G, für die kein Nenner null wird, bilden die  D. Beispiel: 12x − 3 mit G = ℚ: D = ℚ \ {3}, lies „ℚ ohne 3“.

Was ist 12 : 0?
a)Noah hat recht.
b)Mira: 0 · 0 = 0, nicht 12.│Jonas: 12 · 0 = 0, nicht 12.│Elif: 1 000 000 · 0 = 0, nicht 12.
c)0 : 2 = 0, denn 0 · 2 = 0. Jede Zahl mal 0 ergibt 0, nie 12. Deshalb hat 12 : 0 kein Ergebnis.
