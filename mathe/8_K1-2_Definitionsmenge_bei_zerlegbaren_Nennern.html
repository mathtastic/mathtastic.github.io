Merke — Definitionsmenge bei zerlegbaren Nennern
Ein ist genau dann null, wenn mindestens einer seiner null ist. Deshalb man den Nenner. An jedem Faktor liest man eine Zahl ab, die nicht zur gehört. Beispiel mit G = ℚ: Der Nenner x² − 3x = x · (x − 3) wird für x = 0 und x = 3 null, also D = ℚ \ {0; 3}.

▲ STOLPERSTEIN
Bei (x − 3)² gibt es nur eine Zahl: Beide Faktoren sind gleich.
Erst zerlegen, dann ablesen
a)
x² − 4x = x · (x − 4)
x = 0 oder x = 4
D = ℚ \ {0; 4}
x² − 36 = (x + 6) · (x − 6)
x = −6 oder x = 6
D = ℚ \ {−6; 6}
x² − 6x + 9 = (x − 3)²
x = 3
D = ℚ \ {3}
x² + 8x + 16 = (x + 4)²
x = −4
D = ℚ \ {−4}

Weitergedacht
a)D = ℕ \ {6}: −6 gehört nicht zu ℕ.
b)Nenner x² − 49, denn (x + 7) · (x − 7) = x² − 49.
c)Nein. x² ist nie negativ, also ist x² + 4 mindestens 4. D = ℚ.
