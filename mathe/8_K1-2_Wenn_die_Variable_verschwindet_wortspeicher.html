Merksatz „Wenn die Variable wegfällt“ · Lineare Gleichungen · Blatt 3
Diese Wörter passen in den Merksatz:
Aussageleere MengeGrundmengeallgemeingültig
Setze jedes Wort an die passende Lücke — ein Wort pro Lücke.
Aussage — ein Satz, der wahr oder falsch ist. Eine Gleichung ohne Variable ist eine Aussage: wahr wie 6 = 6 oder falsch wie 7 = 2.
leere Menge — eine Menge ohne Element. Man schreibt { }.
Grundmenge — alle Zahlen, die man für die Variable einsetzen darf. Man schreibt G, zum Beispiel G = ℚ.
allgemeingültig — so heißt eine Gleichung, wenn jede Zahl der Grundmenge sie erfüllt. Dann ist L = G.
