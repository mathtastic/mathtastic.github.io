Bruchgleichungen über Kreuz lösen
1
▲ STOLPERSTEIN
Ohne Klammer wird aus 4 · (x − 2) schnell 4x − 2.
Über Kreuz, mit Probe
a) 12 · 5 = 3 · x
60 = 3x | : 3
x = 20
Probe: 12 : 20 = 0,6 = 3 : 5 ✓
b) 4 · (x − 2) = 3 · x
4x − 8 = 3x | − 3x
x − 8 = 0 | + 8
x = 8
Probe: 4 : 8 = 0,5 = 3 : 6 ✓
c) 3 · (2x − 4) = 5 · (x − 2)
6x − 12 = 5x − 10 | − 5x
x − 12 = −10 | + 12
x = 2
Probe: Beide Nenner werden null, 3 : 0 und 5 : 0 gibt es nicht. Also ist 2 keine Lösung.
2
FÜR DIE LEHRKRAFT
Darum kommt D zuerst und der Vergleich mit D am Ende.
Eine Lösung, die keine ist
a)D = ℚ \ {2}│L = { }
b)3 · 0 = 5 · 0 stimmt, denn in jedem Produkt steckt ein Nenner als Faktor, und der ist für x = 2 null. Die Bruchgleichung hat dort keinen Wert.

x = 3 liegt in D: L = {3}
b) D = ℚ \ {−3}
2 · (3x + 9) = 5 · (x + 3)
