Merke — Ausmultiplizieren (Distributivgesetz)
Beim Ausmultiplizieren wird ein in eine verwandelt: Jeder in der Klammer wird mit dem Faktor vor der Klammer multipliziert.
Beispiel: a · (b + c + d) = a · b + a · c + a · d

F
Häufige Fehler
3 · (x + 4) = 3x + 4 → 3 · (x + 4) = 3x + 12. Auch die 4 wird mit 3 multipliziert.
−2 · (a − 5b) = −2a − 10b → −2 · (a − 5b) = −2a + 10b. Minus mal Minus ergibt Plus.
x · (x + 7) = 2x + 7x → x · (x + 7) = x² + 7x. x mal x ist x², nicht 2x.
2 · (4a + 1) − 3 · (a − 2) = 8a + 2 − 3a − 6 → … = 8a + 2 − 3a + 6. Die −3 wirkt auf beide Glieder der Klammer.
M
Merksatz
Beim Ausmultiplizieren wird ein Produkt in eine Summe verwandelt: Jeder Summand in der Klammer wird mit dem Faktor vor der Klammer multipliziert.
L
Für die Lehrkraft
Warum Wege sammeln. Die Rechteckfläche kennt die Klasse seit Klasse 5. Neu ist nur, dass zwei Terme dieselbe Fläche beschreiben. Das Gesetz entsteht aus dem Vergleich, der Name kommt erst im Merksatz.
Taschenrechner: Aufgabe 1 arbeitet mit den echten Hallenmaßen. Wer ohne Rechner arbeiten will, rundet auf ganze Meter (25 · 50 = 1250); das Gesetz zeigt sich genauso.
