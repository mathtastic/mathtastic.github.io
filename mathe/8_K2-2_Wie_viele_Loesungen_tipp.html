Hilfe: eine, keine oder unendlich viele Lösungen

Lineare Gleichungen · Blatt 4
Öffne zuerst Tipp 1. Reicht er nicht, öffne den nächsten. Versuche es danach wieder selbst.
Aufgabe 1 · Erst zusammenfassen
Tipp 1Die Richtung
Fasse zuerst auf jeder Seite die x-Glieder und die Zahlen zusammen.
Tipp 2Der Schritt
Bring dann die x-Glieder auf eine Seite. Fällt x weg, bleibt eine Aussage ohne x. Ist sie wahr oder falsch?
Falsch heißt keine Lösung, L = { }. Wahr heißt: jede Zahl ist eine Lösung, L = ℚ.
Tipp 3Ein Beispiel
Ein eigenes Beispiel:
5x + 1 − 2x=3x + 4
3x + 1=3x + 4| − 3x
1=4
1 = 4 ist falsch, also L = { }.
Aufgabe 2 · Vier ähnliche Gleichungen
a)
Tipp 1Der Schritt
Subtrahiere bei jeder Gleichung zuerst 5x. Was bleibt übrig?
b)
Tipp 1Die Richtung
Vergleiche Gleichung 1 und 2: Was ist gleich, was ist anders? Vergleiche dann Gleichung 2 und 3.
Tipp 2Ein Satzanfang
So kannst du beginnen: „Stehen links und rechts gleich viele x, dann …“
Aufgabe 3 · Andere Grundmenge
a) und b)
Tipp 1Der Schritt
Löse die Gleichung wie immer. Prüfe dann für jede Grundmenge: Gehört deine Lösung dazu?
In ℕ stehen nur 1; 2; 3; …, in ℤ auch die 0 und die negativen ganzen Zahlen, in ℚ auch die Brüche und Dezimalzahlen.
Tipp 2Ein Beispiel
Ein eigenes Beispiel: x = −4 liegt in ℤ und ℚ, aber nicht in ℕ. Für G = ℕ ist L = { }.
c)
Tipp 1Die Richtung
Links und rechts stehen dieselben Glieder. Welche Zahlen der Grundmenge machen die Gleichung wahr?
Tipp 2Ein Beispiel
Ein eigenes Beispiel: 4x + 2 = 2 + 4x ist für jede Zahl wahr. Für G = ℤ ist L = ℤ.
Aufgabe 4 · Ergänze die Lücken
a) und b)
Tipp 1Die Richtung
Wie viele x müssen rechts stehen, damit x beim Umformen wegfällt?
c)
Tipp 1Der Schritt
Rechne aus, was die linke Seite für x = 2 ergibt. Baue rechts einen Term, der für x = 2 dasselbe ergibt.
Tipp 2Ein Beispiel
Ein eigenes Beispiel mit L = {3}: Bei 2x + 2 = ▢x + ▢ ergibt links 2 · 3 + 2 = 8. Rechts passt x + 5, denn 3 + 5 = 8.
Aufgabe 5 · Auf einen Blick
a)
Tipp 1Die Richtung
Nutze, was du in Aufgabe 2 herausgefunden hast. Vergleiche zuerst die x-Glieder, dann die Zahlen. Gibt es genau eine Lösung, rechne sie im Kopf aus.
b)
Tipp 1Der Schritt
Setze 0 in die Gleichung mit L = {0} ein. Was ergeben beide Seiten?
Tipp 2Ein Satzanfang
So kannst du beginnen: „Bei L = {0} ist …“
