Begründung: Aus 5x − 15 = 4x wird x = 15, die 3 wird mit 5 multipliziert. Allgemein wird aus 5x − 5k = 4x die Lösung x = 5k.
Drei ähnliche Gleichungen
a)
D = ℚ \ {0; 1}
5 · (x − 1) = 4 · x
5x − 5 = 4x | − 4x
x − 5 = 0 | + 5
L = {5}
D = ℚ \ {0; 2}
5 · (x − 2) = 4 · x
5x − 10 = 4x | − 4x
x − 10 = 0 | + 10
L = {10}
D = ℚ \ {0; 3}
5 · (x − 3) = 4 · x
5x − 15 = 4x | − 4x
x − 15 = 0 | + 15
L = {15}
b)L = {50}
c)Die Lösung ist immer das Fünffache der Zahl im rechten Nenner.
2
▲ STOLPERSTEIN
Ohne Klammer wird nur x mit −1 multipliziert, die 1 nicht.
Wo steckt der Fehler?
Lotta vergisst die Klammer: −1 wird mit dem ganzen Nenner x + 1 multipliziert, nicht nur mit x. Die Probe zeigt es: 3−2 + 1 = −3, nicht −1.
D = ℚ \ {−1}
3 · 1 = −1 · (x + 1)
3 = −x − 1 | + x
x + 3 = −1 | − 3
x = −4 liegt in D: L = {−4}

▲ STOLPERSTEIN
Aus (x + 2) · (x + 2) wird x² + 4x + 4, nicht x² + 4.
Summen in Zähler und Nenner
a) D = ℚ \ {−2; 1}
(x + 2) · (x + 2) = (x + 4) · (x − 1)
x² + 4x + 4 = x² + 3x − 4 | − x²
4x + 4 = 3x − 4 | − 3x
x + 4 = −4 | − 4
x = −8 liegt in D: L = {−8}
b) D = ℚ \ {−2,25; −0,25}
(x − 1) · (4x + 9) = 0,5x · (8x + 2)
4x² + 5x − 9 = 4x² + x | − 4x²
5x − 9 = x | − x
4x − 9 = 0 | + 9
4x = 9 | : 4
x = 2,25 liegt in D: L = {2,25}
