1
▲ STOLPERSTEIN
Viele setzen x25 = 23 an. 2 : 3 vergleicht die Kinder im Bus mit den übrigen, nicht mit der ganzen Klasse.
Die Klasse
a)G = {0; 1; 2; …; 25}, denn es gibt nur ganze Kinder.
b) x25 − x = 23
3 · x = 2 · (25 − x)
3x = 50 − 2x | + 2x
5x = 50 | : 5
x = 10
D = {0; 1; …; 24}│L = {10}
10 Kinder kommen mit dem Bus, 15 nicht.
c) 26 − 10,4 = 15,6
3 · 10,4 = 2 · 15,6
31,2 = 31,2
Die Rechnung stimmt. 10,4 liegt aber nicht in der Grundmenge: L = { }. Bei 26 Kindern kann das Verhältnis nicht genau 2 : 3 sein.
2
▲ STOLPERSTEIN
Viele setzen 200x = 14 an. Die 300 ml Wasser sind aber schon im Glas.
Saftschorle
a) 200300 + x = 14
4 · 200 = 1 · (300 + x)
800 = 300 + x | − 300
x = 500│500 ml Wasser dazu
b) 200300 + x = 1
1 · 200 = 1 · (300 + x)
200 = 300 + x | − 300
x = −100
c)Luca müsste 100 ml Wasser wegnehmen. Das geht nicht: L = { }.
3
▲ STOLPERSTEIN
Wer bei 1 = 8 stehen bleibt, hat die Frage noch nicht beantwortet. Aus der falschen Aussage folgt L = { }.
Das Zahlenrätsel
a) 1 + x8 + x = 12
2 · (1 + x) = 1 · (8 + x)
2 + 2x = 8 + x | − x
2 + x = 8 | − 2
x = 6
D = ℚ \ {−8}│L = {6}
b) 1 + x8 + x = 1
1 · (1 + x) = 1 · (8 + x)
1 + x = 8 + x | − x
1 = 8 ist falsch: L = { }
Der Nenner bleibt immer um 7 größer als der Zähler. Beide sind nie gleich.
