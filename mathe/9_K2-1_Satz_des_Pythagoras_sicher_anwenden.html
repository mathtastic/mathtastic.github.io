1
▲ STOLPERSTEIN
Finn quadriert die Katheten und vergisst die Wurzel.
Die Katheten wachsen
a)a² + b² = 25, 100, 225, 2500 → c = 5, 10, 15, 50 cm
b)Nein. Doppelt so lange Katheten: a² + b² wird viermal so groß (25 → 100), c nur doppelt so lang (5 → 10). Mit k-mal so langen Katheten ist auch c k-mal so lang.
c)Jedes Vielfache passt, z. B. 10, 24, 26 und 15, 36, 39.
