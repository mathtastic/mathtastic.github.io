Quadratische Funktionen

1Normalparabel und Streckfaktordie Form der Parabel
y = a · x²
a = 1: Normalparabel, S(0 | 0)
a = 2: gestreckt, enger
a = 0,5: gestaucht, weiter
a = −0,5: nach unten geöffnet
Ist der Betrag von a größer als 1, wird die Parabel gestreckt, ist er kleiner als 1, gestaucht.
2Die ScheitelpunktsformScheitel sofort ablesen
y = a · (x − xS)² + yS
Scheitelpunkt S(xS | yS)
y = 0,5 · (x − 2)² + 3
S(2 | 3)
In der Klammer steht x − xS. Bei (x + 1)² ist xS = −1.
3Allgemeine Form und ScheitelpunktformelScheitel berechnen
y = ax² + bx + c
c ist der y-Achsenabschnitt: Für x = 0 ist y = c.
xS = −b2a
yS = c − b²4a
Beispiel y = x² − 4x + 1
xS = 42 = 2
yS = 1 − 164 = −3, also S(2 | −3)
4Mitternachtsformel (abc-Formel)Nullstellen berechnen
für ax² + bx + c = 0
x1,2 = −b ± b² − 4ac2a
Diskriminante D = b² − 4ac
D > 0: zwei
D = 0: eine
D < 0: keine
5Nullstellen berechnenb mit Vorzeichen
x² − 5x + 6 = 0
a = 1, b = −5, c = 6
D = 25 − 24 = 1
x1,2 = 5 ± 12
x1 = 3, x2 = 2
Schneller ohne Formel: x² = 25: x = 5 oder x = −5. x² − 8x = 0: x · (x − 8) = 0, x = 0 oder x = 8.
6Parabel und Geradegleichsetzen
Gerade mit der Parabel y = x² gleichsetzen, alles auf eine Seite bringen, D berechnen. D sagt, wie die Gerade liegt.
y = x + 2x² − x − 2 = 0D = 9SekanteS1(2 | 4), S2(−1 | 1)y = 2x − 1x² − 2x + 1 = 0D = 0TangenteS(1 | 1)y = −2x² + 2 = 0D = −8Passantekein Schnittpunkt

y = (x + 1)² − 2, also S(1 | −2)
✓So ist es richtig
S(−1 | −2)
In der Klammer steht x − xS. Aus x + 1 wird x − (−1).
✗So geht es schief
x² − 5x + 6 = 0: x1,2 = −5 ± 12
✓So ist es richtig
x1,2 = 5 ± 12, also 3 und 2
b = −5 mit Vorzeichen einsetzen: −b = 5.
